## Disclosure labels

The default label is `fully-free`. Support Desk uses `external-account` for optional guest tickets protected by Cloudflare Turnstile. Only administrators enabling that mode need a Cloudflare account and site/secret keys. The integration works with Turnstile Free. Standard tickets use Moodle accounts; optional Magic Link sign-in uses a separate free GPL plugin in the same Moodle site. No feature requires a paid plan, so `paid-service` is not declared. Required versus optional external dependencies are discussed in https://github.com/camp-registry/camp-docs/issues/5.

## Scope

Plugins under the separate 108design source-available licence are excluded from this claim. The Generico contribution fork is excluded as well. Each plugin retains its own licence and upstream attribution.

CAMP applies this manifest to existing listings whose source repositories belong to 108design, including listings discovered later. The manifest has exclusions and per-plugin overrides; it does not implement a licence filter. Review and update it before another plugin is listed or its service requirements change.

This repository declares listing ownership and contact details. Plugin releases are published separately.
