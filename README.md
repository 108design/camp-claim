## Disclosure labels

The default label is `fully-free`. Support Desk uses `external-account` and `paid-service` to disclose its optional Cloudflare Turnstile integration. Turnstile requires a third-party account and API keys for guest ticket submission; signed-in ticket use works without that integration. `paid-service` follows CAMP’s current definition, which includes API-key-backed commercial services; it does not mean that Support Desk requires a paid subscription.

## Scope

Plugins under the separate 108design source-available licence are excluded from this claim. The Generico contribution fork and the owner-use H5P migration tool are excluded as well. Each plugin retains its own licence and upstream attribution.

CAMP applies this manifest to existing listings whose source repositories belong to 108design, including listings discovered later. The manifest has exclusions and per-plugin overrides; it does not implement a licence filter. Review and update it before another plugin is listed or its service requirements change.

This repository declares listing ownership and contact details. Plugin releases are published separately.
